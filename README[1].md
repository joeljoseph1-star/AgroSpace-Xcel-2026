# AgroSpace Xcel — FieldShift

NASA Space Apps Challenge 2026 prototype.

## Files
- index.html — main website
- styles.css — website styling
- script.js — interactive Leaflet map and field analysis demo

## GitHub Pages
Repository → Settings → Pages → Deploy from branch → main → / (root) → Save.

The website expects the existing logo file:
`agrospace-xcel-logo[1].jpeg`

The map uses Leaflet and OpenStreetMap tiles through CDN/internet access.

# AgroSpace Xcel — NASA-style FieldShift website

This is a GitHub Pages-ready static website.

## Files
- index.html
- styles.css
- script.js
- images/earth-satellite.jpeg — the Earth/satellite photo supplied for the hero background
- images/lim-wei-jiun.jpg — the supplied portrait

## GitHub Pages
Upload all files from this folder to the root of your GitHub repository. Keep the `images` folder and its files together with `index.html`.

Then enable GitHub Pages from:
Settings → Pages → Deploy from a branch → main → /(root).

## Design direction
The design uses a dark Earth-observation hero, editorial typography, large imagery, data cards and a clear science/technology information hierarchy inspired by the visual approach of NASA Science, without copying NASA branding.

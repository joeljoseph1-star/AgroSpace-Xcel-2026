# AgroSpace Xcel — FieldShift Website

NASA Space Apps Challenge 2026
Challenge: Field Shift — Adapting Farms with NASA Data

## GitHub Pages
1. Extract this ZIP.
2. Upload the contents of the extracted folder to the root of your GitHub repository.
3. Make sure `index.html`, `styles.css`, `script.js` and the `images` folder are in the repository root.
4. Go to Settings → Pages → Deploy from branch → choose `main` and `/ (root)` → Save.

## Included
- NASA-inspired dark hero with space background
- Full FieldShift dashboard content from the supplied prototype screenshots
- Interactive Leaflet map
- Location reverse-geocoding when the map is clicked
- Field-health dashboard
- Year-at-a-glance chart
- Crop rotation recommendations and alternatives
- Long-term trends
- Method/workflow section
- Five clickable team member cards with the supplied team photos

## Note
The field values in this prototype are demonstration values based on the supplied FieldShift concept. The map interaction is real, but the displayed NASA-style indicators are not a live NASA API feed until a NASA data endpoint is connected.
